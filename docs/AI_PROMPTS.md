# AI Prompt Log

This document records substantive prompts used with AI systems during
the development of the PCSE Hardware project.

## Format

Each entry should contain:

- Date
- Tool
- Purpose
- Prompt summary
- Result
- Validation performed

## Example

### 2026-09-23

**Tool:** ChatGPT

**Purpose:** Debug Verilator/Ibex simulation setup.

**Prompt summary:** Asked for diagnosis of the Ibex simulation build
procedure and the appropriate current build flow.

**Result:** Received suggested commands and documentation references.

**Validation:** Commands were tested locally before being adopted.
